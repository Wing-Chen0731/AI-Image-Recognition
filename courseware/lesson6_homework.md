# 第六课时课后作业：Flask Web 图像识别系统

> 适用对象：第一次把 AI 模型接入 Web 页面的同学  
> 作业目标：跑通本节课的 Web 图像识别系统，并能讲清楚前端、后端、模型之间如何协作

---

## 一、作业总目标

本次作业不是只看你能不能打开网页，而是要确认你真正理解下面这条完整流程：

```text
浏览器选择图片
-> 前端预览图片
-> 前端把图片上传到 Flask 后端
-> Flask 保存图片
-> Flask 调用 PyTorch 模型预测
-> Flask 返回 Top-3 JSON 结果
-> 前端显示类别名和置信度
```

完成作业后，你应该能回答：

1. `app/web_app.py` 负责什么。
2. `templates/index.html` 负责什么。
3. `/predict` 接口为什么要返回 JSON。
4. 为什么模型不能每次请求都重新加载。
5. 如果页面报错，应该先检查哪些地方。

## 四、软件设计任务：联系 CPSC210

### 任务 6：说明本项目里的 CPSC210 思想

请从下面 5 个角度中任选 3 个进行说明。

| CPSC210 角度 | 对应本项目 |
|---|---|
| 职责划分 | `web_app.py` 管后端，`index.html` 管页面，`model_loader.py` 管模型 |
| 抽象 | `ModelLoader` 规定模型加载接口 |
| 低耦合 | 前端只调用 `/predict`，不直接接触 PyTorch |
| 单例 / 缓存 | `_model` 和 `lru_cache` 避免重复加载 |
| 异常处理 | 数据集、模型、上传文件出错时要给出错误 |

每个角度至少写 1 段话，说明：

1. 这个思想是什么意思。
2. 本项目哪段代码体现了这个思想。
3. 这样设计有什么好处。
